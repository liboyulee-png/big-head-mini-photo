# 效果与细节验收

生成前先看原照，列出能证明「还是这个人、这个场景、这个动作」的锚点。除人物与物件本身，还要看本图关键元素之间的关系：谁支撑或接触谁、从哪里连接、谁在谁前面、哪些部分可见或被遮挡、相对位置与光线如何。只记录与当前照片的辨识度和动作可信度有关的关系；比例变化可改变局部坐标，但不能随意颠倒这些关系。同时写出本模式要达到的明显头身效果，避免保真要求压弱效果。

## 通用变形规划：逐部位、逐关系判断

每次只针对当次原照做一张简短的内部检查表，不套固定姿势模板。逐项看头颈、肩胸与髋部、左/右可见手臂、左/右可见腿、与人物相连的物件，以及附近不会随人物缩放的场景物件。只量照片里能判断的部分；被挡住、出框或根本不存在的部位不要推测补全。**先判物件归属与尺度，再判接触**：场景固定物保持原尺度和位置；穿戴、拿握、骑乘、推拉、牵引或悬挂的物件可随人物移动，但“可移动”不等于“与身体等比缩小”。原地大头模式中，衣鞋可适配小身体，自行车、乐器、行李等独立物件通常维持其现实尺寸；原场景微型人模式中，与人物组成微型主体的物件随整体缩小。具体仍以原照中的用途和所选模式为准。物件碰到地面或家具，也不自动变成场景固定物。给各部位写所选模式的尺寸目标后，再给每个关键末端或物件关系分类：

| 关系类型 | 从原照如何判断 | 变形与验收 |
| --- | --- | --- |
| 与场景固定物实际接触或承重 | 手脚、臀部或身体贴住地面、固定家具、栏杆、树枝等，接触点对动作有意义 | 保留与原支撑物的接触和受力；相连肢体可偏离默认缩短幅度，但仍须从缩小后的肩/髋自然连接。不要因此冻结整个人或其他自由肢体。 |
| 与人物相连并可随其移动 | 衣服、帽子、鞋、背包、骑乘、手持、推拉或牵引的物件等跟随人物，而非固定在场景中 | 分别确定物件在所选模式下的尺度和新位置，再保留与人物的连接、前后层级及真实接触；若物件也触地，重新确定合理落点与阴影，不把它钉在原坐标。 |
| 多点或柔性连接 | 同一物件连着多处身体，或通过背带、绳、线、吊带等连接人物与物件 | 逐一保留各连接端、连续走向和必要的松紧或悬垂关系；允许曲线与角度随新比例改变，不能只保留某一个端点而让其余连接断开。 |
| 没有固定接触的自由端点 | 抬起、伸出、摆动、腾空的手脚或其他身体末端，没有被场景物体固定 | 随相连肢体和躯干按模式比例调整长度、方向与末端位置；保留动作含义，不为维持原图像素坐标而留下成人尺寸的局部。 |
| 遮挡或画框裁切 | 全部或部分被头发、衣物、身体、物件遮住，或位于画面外 | 保留可见范围和前后关系；只修复比例变化实际露出的背景，不凭空画出隐藏的手脚或出框部位。 |
| 场景固定结构 | 道路、建筑、树木，以及未被人物搬动或推动的家具等背景结构 | 保持现实尺度、透视和主要位置；仅修补人物变形后露出的局部。 |

同一人物的左右肢体要**分别**判断：一侧有支撑不等于另一侧也固定。对同时连着人物和场景的可移动物，先定物件的新尺度与位置，再逐一恢复手—物、带—物、轮或底部—地面的接触，不以其中一处接触冻结整个物件。最后做一次整体比例预检：头部变大、躯干变小后，每条可见且无固定接触的肢体是否也随之收小；穿戴、手持或推拉物是否仍与人物连贯；是否有任何一句提示词一边要求缩小身体，一边要求自由端点留在原位置。若某条肢体必须保住与场景固定物的接触，就明确放宽该条肢体的数字目标，而不是取消其他部位的缩小。

## 通用局部一致性扫描

把原照和结果并排看全图，再放大检查**每个变形部位与相邻部位的交界**，以及主要物件的连接处。不要只复查提示词里点名的手、头发或背带；不同照片会暴露不同缺陷。按原照逐处判断：

1. **数量与身份**：可见的人、肢体、配饰和主要道具是否多出、消失、复制或换成另一种；脸、衣着、显著标识是否仍可辨。
2. **轮廓与连接**：原本分开的部位是否被粘成一团，原本相连的部位是否断开；肢体是否从正确关节伸出，柔性物件是否从正确端点连续到另一端，不穿过身体或物件。
3. **接触与受力**：握、背、坐、踩、靠、牵等动作是否有可信的落点、松紧、压痕和阴影；被支撑物和自由端点是否各按自己的关系移动。
4. **遮挡与尺度**：前后次序、露出范围、透视和相对大小是否仍合乎原照与所选模式；不补画原本被遮住或出框的内容，也不让局部保留不协调的原尺寸。
5. **光影与材质**：局部修补处的光线方向、边缘、清晰度和材质是否与相邻区域一致；画质提升不掩盖结构错误。

发现清单外的新问题，按这五类判断它是否影响身份、动作、比例或关键物件关系；影响时局部修复并复核相邻区域。轻微、无关的纹理变化不构成重试理由。

## 生成前：把验收点写进首次提示词

先写所选模式的可见头身比例，再从原照挑出实际存在、生成时最容易丢失的细节。把对应验收点写成**能在结果中直接看到的要求**；下表只是判断方法的例子，不是固定物件清单，不要整段复制或罗列原照没有的物件。

| 原照中出现的情况 | 首次提示词要写清的画面结果 |
| --- | --- |
| 可辨认的脸、发型、衣着或特殊配饰 | 仍是同一人的脸型、表情、年龄感与发型；保留本图衣服的颜色、款式和关键配饰。头颅放大与肩胸收小都要可见，不能只放大脸。 |
| 长发垂过肩胸 | 头顶发丝可随头颅放大；肩胸处的发束仍沿原照方向下落，保留厚薄、外轮廓与发束间的空隙，不靠加厚垂发制造大头。 |
| 肢体有接触、抬起或伸展 | 按上表分类每条可见肢体的端点，分别写明接触、自由移动或遮挡状态，以及从肩/髋到末端的连接与动作方向；高举过头的手仍高于新头顶。 |
| 身体同时受多个物件支撑或约束 | 分别标出每处实际接触、受力和遮挡关系，再调整肩髋与相连肢体；不要把一处接触误当成所有手脚都必须留在原坐标。 |
| 手脚被袖口、身体、花草或道具遮住 | 写明哪些手脚完全可见、部分可见或完全被遮住；部分露出的鞋面、手掌等保留原有遮挡边界，不为了补齐小身体而画出原图没有的部分。 |
| 人物、衣物、道具或环境物件之间有关键重叠或连接 | 写明接触与连接点、前后层级、可见与被遮挡的部分，以及必要时从哪里再次露出；保留关系，而不只是保留各个物件的存在。 |
| 柔性连接或多点接触的物件 | 写明实际连接端、连续路径、与相邻部位的前后次序及松紧或受力；例如背带贴合肩膀并接到包，绳索或吊饰保持两端连接，手持物与手真实接触，不悬空或穿透。 |
| 原场景有明显结构、物件或光线方向 | 点名最能辨认地点的少数结构与物件，维持它们的现实尺度、位置关系、透视和光线；只补人物变形后露出的局部背景。 |

提示词最后用一句话约束真实照片质感、自然皮肤与可信阴影。若原照画质需要改善，再要求自然提升清晰度和曝光；不要为画质优化改变身份、季节或光线方向。以上写法用于提高首版成功率，生成后仍须按下文逐项验收。

## 改动边界

- **必须保留的核心**：同一人的可辨认面容与年龄感、主要发型、衣服款式和颜色、动作语义，以及能认出原地点的场景结构和关键道具。手脚数量正确、接触和阴影可信。长发照片要特别对照原图的头顶、脸侧、肩部和胸前四处发量，保留垂发方向与发束间的空隙。
- **允许为效果重建**：头部尺寸、发丝边缘、颈肩、肩宽、躯干、四肢、手臂角度与非承重落点、衣褶、人物遮挡区域及邻近背景。与环境实际接触的端点优先保留支撑关系；随身物可随人物移动或按模式适配，但类型与连接不能改变；环境固定物件保持原有现实尺度。头顶发丝可随头颅放大；肩部以下的长发不能与头部等比膨胀，其外轮廓和厚薄只作必要的局部调整。
- 头部或头发变大造成合理遮挡可以接受；仍露出的书架、画框、柜体边缘等尽量沿原有位置和线条延续。不能为制造大头效果把整幅家具搬动、复制或凭空替换背景。
- 对近景半身照，允许袖口、手臂和杯子附近局部重建；必须保持原来的「手托脸」「坐在桌边」等姿势含义，不能因保护这些局部而交付几乎没有大头小人效果的图，也不能凭空增添腿部。
- **遮挡状态是细节锚点**：原图只露出托腮的手、另一只手藏在衣袖或身体后面时，缩小身体后仍应保持这种可见关系。不能为了补齐人体结构，在杯子后、袖口边或桌面上凭空露出原照看不到的手掌/指尖；只有原图确实可见或用户明确要求改变动作时才显示。检查不是只数有没有“第三只手”，还要看本来隐藏的手是否被无依据地画出来。
- **关系也是锚点**：原图中关键元素的支撑、连接、遮挡和前后次序应保持可信；不能因缩放或局部修饰，让原本被挡住的部分凭空露出、让接触点悬空，或让连续物件断开。允许随比例变化微调位置和角度，但必须重新检查关系是否仍成立。
- **相邻部位的轮廓和连接是细节锚点**：变形后，原本独立的轮廓或间隙仍应可辨，原本相连的物件仍须连续；避免把手臂与肩膀、衣物与道具等挤成一团，或让绳、带、线、头发、饰品等从不合理的位置长出。柔性连接可随新比例改变弧度，但要顺着真实受力方向，不弯成无依据的钩形。背带与肩部是这条规则的一个例子，不是唯一需要检查的部位。

## 摄影质感

原图成像质量一般时，可在大头小人转换中自然改善曝光、动态范围、白平衡、噪点、细节层次与适度锐度，让人物和原场景呈现清晰、协调的专业摄影照片观感。保留原场景的天气、光线方向和空间关系；保留真实肤质，不把磨皮、过度锐化、饱和度拉满或凭空增加光源当成“专业”。若是局部返修，沿用已认可版本的影调和清晰度，不为修一个肩膀重新调色整张图。

## 提示词与检查

在模式提示词后补充本张照片的身份/场景锚点、必须出现的头身差异，以及允许重建的局部。只从当次用户原照提取人物、动作和场景信息；比例与尺度按所选模式的文字规则确定。

结果逐项与原照比对：

1. 头身比例一眼达到所选模式；模式①须同时有明显大头与小身体，不只略微放大脸。
2. 仍能认出同一个人；五官、年龄感、表情、发型没有变成另一位人物。长发的肩部体积没有明显膨胀，衣服和背景仍能在原有发束间自然露出。
3. 对照生成前的内部检查表，逐项核对左右可见手臂和腿的长度、关节连接、末端位置及可见范围；有环境接触的部位仍接触原支撑物，自由肢体与缩小后的躯干同尺度，穿戴和手持物连接不断，隐藏或出框的部位未被凭空补全。任何一处无真实支撑解释的成人尺寸肢体留在小身体上，即使肢体数量和动作方向正确，也判为比例失败。再核对本图关键元素的前后遮挡、受力与光影；一个物件仍在画面里，不代表它与人物或环境的关系仍正确。
4. 原场景可辨；主体外的桌椅、书架、画框、柜体等主要结构没有明显整体漂移或凭空增删。局部衣褶、发丝、物件遮挡变化可以接受。
5. 构图、机位、透视、光线方向、皮肤与环境质感协调；若原图画质一般，提升后应自然清晰、细节可信，没有塑料皮肤、强锐化边缘或新造的光影。

局部细节变化本身不是失败；按整体效果、身份与场景辨识度、动作合理性综合判断。若有多个版本，先确定每版是否满足主效果与关键关系，再看待修的局部是否改善；只有局部更好却破坏已达标内容的新版，不应自动替换旧版。用户在都满足基本要求的版本中明确偏好某版时，按其偏好选择。对明显不合格图，回到原照重试并强调失败点；不要把失败图作为下一轮编辑底图。生成式编辑可能重绘整个画面，提示词无法保证背景像素完全不变。若用户明确要求逐像素保留，应选用支持局部蒙版或原图背景合成的编辑方法，并对合成边缘单独检查。
