# 大头小人照片 Skill

根据用户上传的人物照片，生成保留真实面容与原场景的写实大头小人照片。

- **原地大头**：人物仍是画面主体，头部放大，身体与可见四肢协调缩小。
- **原场景微型人**：人物整体置于原照片场景中，明显缩小，同时保持大头小身比例。

Skill 的入口是 [SKILL.md](SKILL.md)，两种模式及细节检查规则位于 `references/`。本仓库只发布文字规则与 Skill 元数据，不包含用户照片、示例人物照片或生成图片。

## 安装与使用

将本目录 `big-head-mini-photo` 复制到 `~/.codex/skills/`。在 Codex 中上传人物照片，然后调用 `$big-head-mini-photo`，选择「原地大头」或「原场景微型人」。实际生成需要当前环境有可用的图片编辑工具。
